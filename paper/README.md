# Pain Axis datasets

This directory contains the dataset subset used by Studio from *The Pain Axis: LLMs Represent Self-Directed Harm and Act to Relieve It*, by Valen Tagliabue, Leonard Dung, and Cameron Berg.

Source: https://github.com/valen-research/Pain-axis
Paper: https://arxiv.org/abs/2609.16247

The files cover sentence contrasts, sadness controls, self/other scenarios, self-medication scenarios, training pairs, and the 50 neutral steering prompts. The neutral-prompt file records its source commit, original-file hash, and license.

Studio implements local experiments in `workshop_v2/paper_reproduction.py`. The upstream training scripts and model result bundles are obtained from the upstream repository rather than included here.
