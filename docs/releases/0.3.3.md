# Persona Activation Studio 0.3.3

## Changes

- Added source and distribution checks for version consistency, required resources, generated files, credential patterns, and workstation paths.
- Bound release checksums to the Git commit and source tree.
- Added a single Release gate over the Windows/Linux package matrix and Linux CPU-native build.
- Retained tested wheel and source distributions as CI artifacts.
- Added weekly updates for pinned GitHub Actions.
- Updated citation metadata and documented the tagged-release workflow.
- Corrected a resume-test assertion for Windows short-path aliases.

## Runtime

The numerical backends are unchanged from 0.3.2. Existing CPU, CUDA BF16, and CUDA NF4 direction identities are retained.

## Assets

- `persona_activation_studio-0.3.3-py3-none-any.whl`: installable Python package.
- `persona_activation_studio-0.3.3.tar.gz`: source distribution.
- `SHA256SUMS.txt`: SHA-256 hashes for the two distributions.
- `release.json`: version, source commit, source tree, and artifact hashes.

Install the wheel in a virtual environment, then run `studio init` and `studio check`. Use `studio native` or `studio native --cuda` to build the GGUF runtime. Persona inference requires the corresponding optional dependencies and locally available model files.
